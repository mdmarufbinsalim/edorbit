# Third-party assets

Record every texture, model, image, or font used in EdOrbit with its source and licence. Assets must be compatible with MIT redistribution.

| Asset                    | Used in                                             | Source                                                              | Licence                                    |
| ------------------------ | --------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------ |
| Geist / Geist Mono fonts | App UI                                              | Vercel, via `next/font/google`                                      | SIL Open Font License 1.1                  |
| KaTeX fonts and CSS      | Equation rendering                                  | `katex` npm package                                                 | MIT                                        |
| Europe coastline data    | History maps (`packages/history/src/geo/europe.ts`) | Natural Earth 1:50m land, via the `world-atlas` package, simplified | Public domain (world-atlas packaging: ISC) |

No third-party images or textures are used yet. Illustrations, including the Gutenberg Bible page drawing, are hand-drawn SVG in the repository. Add rows here when textures are introduced.
